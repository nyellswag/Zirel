Test Zirel in 10 Minutes

  1. Create a project.
  2. Add two characters.
  3. Add one faction.
  4. Add one event.
  5. Create three to five relationships.
  6. Open Logic Warnings.
  7. Open Graph View.
  8. Export your project if you want a backup.
  9. Submit feedback.

Known Limitations

  • User accounts are still basic.
  • No cloud sync yet.
  • No AI analysis yet.
  • Logic warnings are rule-based and may miss issues.
  • Design and UX are still evolving.

Data Safety Note

This is an early MVP. Please do not add highly sensitive, confidential, or irreplaceable writing material yet.

You can export your project data as JSON from the project dashboard to keep a local copy.
