# Zirel: журнал изменений

В этом файле фиксируются только подтвержденные реализованные возможности.

## Реализовано

- Добавлен фирменный favicon Zirel с прозрачным фоном и отдельными версиями для браузерных вкладок и Apple Touch Icon.
- Закрытая бета ограничена 100 обычными аккаунтами с одноразовыми приглашениями, сроком действия и отзывом кодов через Admin → Invites.
- На первом экране главной добавлен адаптивный индикатор заполнения закрытой беты; публичные страницы остаются доступны без авторизации.
- Полностью обновлены публичные Landing, Beta, Roadmap, Whitepaper и FAQ в единой интерактивной стилистике Zirel.
- Формы, страницы создания сущностей и рабочие пространства проектов унифицированы и адаптированы для мобильных экранов.
- Terms и Privacy переработаны в согласованном legal-дизайне с общей шапкой и футером сайта.
- Структура Flask-приложения через app factory.
- Локальная поддержка SQLite.
- Поддержка PostgreSQL на деплое через `DATABASE_URL`.
- Миграции Flask-Migrate.
- Регистрация, вход и выход пользователя.
- Хеширование паролей.
- Поле роли пользователя.
- Поддержка администратора.
- Защищенные маршруты проектов.
- Проекты, принадлежащие пользователям.
- Админ-панель.
- Админские страницы для пользователей, обратной связи, contact-сообщений и заявок списка ожидания.
- Админские удаления пользователей, заявок списка ожидания, feedback-сообщений и contact-сообщений.
- Страница списка ожидания перед запуском.
- Отправка заявок в список ожидания.
- CRUD для проектов.
- CRUD для персонажей.
- Массовое удаление и полная очистка персонажей.
- CRUD для фракций.
- Массовое удаление и полная очистка фракций.
- CRUD для событий.
- Массовое удаление и полная очистка событий.
- CRUD для связей.
- Массовое удаление и полная очистка связей.
- Конструктор связей с предпросмотром `source -> relation -> target`.
- Подсказки и человекочитаемые названия типов связей.
- Очистка связей, связанных с удаленными сущностями.
- Rule-based Logic Engine.
- Динамическая страница предупреждений.
- UI предупреждений с severity и category.
- Graph Workspace на Cytoscape.js.
- API данных графа.
- Фильтры, поиск, инспектор деталей и поиск пути в графе.
- Экспорт проекта в JSON.
- Импорт проекта из JSON.
- Форма обратной связи.
- Форма контакта.
- Публичная страница Beta.
- Страница FAQ.
- Страница Whitepaper.
- Страница Roadmap.
- Страницы Terms и Privacy.
- Темный футуристичный SaaS-стиль на публичных и внутренних страницах.
- Базовая документация проекта в `docs/`.
- Переработанные страницы Sign In / Sign Up в стиле modal-референсов.
- Кнопка-глаз для показа и скрытия пароля на auth-страницах.
- Переработанные страницы Terms и Privacy в отдельном темном legal-document стиле.
- Центрированная верхняя подпись на Terms и Privacy.
- Текстовая кнопка `Print` на Terms и Privacy.
- Старое hex-мини-лого заменено на минималистичный ромбовый знак в стиле Wishlist.
- Общий Legal Center и Disclaimer удалены; в интерфейсе оставлены отдельные Terms и Privacy.
- Graph Workspace переработан в полноэкранный fixed-layout по HTML-референсу с собственным topbar, sidebars, inspector и status bar.
- Warnings Page переработана в полноэкранный workspace по HTML-референсам с topbar, sidebar-фильтрами, warning-карточками, inspector и status bar.
- Projects Page переработана в полноэкранный workspace по HTML-референсу с topbar, left sidebar, project cards, right quick actions panel, поиском, сортировкой и Grid/List view.
- Graph Workspace переведен на кастомную constellation map на HTML/SVG/canvas вместо Cytoscape на странице графа.
- API графа расширен стабильными `positions`, визуальными цветами и знаками узлов без изменения базы данных.
- Миникарта Graph Workspace теперь строится из реальных позиций узлов и связей.
- В Graph Workspace сохранены поиск, фильтры, inspector, поиск пути, connected-only, focus selected и перетаскивание узлов.
- Публичная Contact-страница очищена от лишних верхних reason chips.
- Feedback получил выбор темы сообщения для бета-обратной связи.
