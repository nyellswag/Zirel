# Zirel: решения

## Flask-монолит

Zirel сейчас построен как Flask-монолит. Это видно по app factory в `app/__init__.py`, одному основному blueprint в `app/routes.py`, Jinja2-шаблонам и общим статическим файлам.

## Flask-SQLAlchemy и Flask-Migrate

Работа с базой данных реализована через Flask-SQLAlchemy, а изменения схемы управляются через Flask-Migrate / Alembic.

Это видно в `requirements.txt`, `app/__init__.py` и директории `migrations/`.

## Flask-Login для авторизации

Авторизация реализована через Flask-Login.

Пользователи имеют хешированные пароли, а маршруты проектов защищены требованием входа.

## Владение проектами

Проекты принадлежат пользователям через `Project.user_id`.

Обычный пользователь видит только свои проекты.

Администратор может видеть все проекты.

## Динамические предупреждения

Логические предупреждения генерируются динамически в `app/logic_engine.py`.

Они не сохраняются в базе данных.

## Граф на основе существующих связей

Граф строится из существующих сущностей проекта и связей.

Отдельная graph database или модель сохраненных layout-настроек сейчас не используется.

## Режим списка ожидания

`WISHLIST_MODE` используется для переключения публичного сайта во временный режим списка ожидания, при этом администратор сохраняет доступ к админским маршрутам.

## Переносимость через JSON

Экспорт и импорт проекта используют JSON, чтобы поддержать резервные копии и переносимость данных.

Предупреждения не импортируются как записи базы данных, а генерируются заново.
